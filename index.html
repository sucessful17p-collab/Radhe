BUILT-IN DEMO GUIDE

How to run SignalWard

ⓘ
1 · Generate a sensor event

Use Stable, Watch, Noisy Sensor, or Escalation. Notice that weak evidence produces an Evidence Check instead of a confident patient-pattern score.

2 · Try Scenario Lab

Change fictional measurements or add a short English note, then evaluate. The response includes the synthetic tier, contributing reasons, evidence confidence, and a workflow prompt.

3 · Ask the Review Agent

It re-runs bounds and evidence-policy checks on the same fictional inputs. This transparent rule-based reviewer is local; it is not an external LLM or clinician.

4 · Explore generated vision

Select a posture, analyze its generated canvas geometry, and compare the confidence gate. No camera is opened and no picture is uploaded.

5 · Try device adapters

Open Device API Lab, choose a simulated home device and sample mode, then inspect the normalized JSON packet and measurement units.

6 · Close the human loop

Review the alert queue, log a demo caregiver activity, and acknowledge an alert. Offline mode queues ordinary demo actions until reconnection.

Safety boundary: everything here is fictional simulation. Scores and next moves are software-demo outputs, not diagnosis, treatment advice, or real-world monitoring.
